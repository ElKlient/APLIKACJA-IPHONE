# Instrukcja obowiązkowa dla agentów

Przed wykonaniem jakiejkolwiek pracy w tym repozytorium:

1. Przeczytaj w całości START_HERE.md.
2. Przeczytaj HANDOFF.md.
3. Sprawdź aktualny stan gałęzi main i ostatnie commity.
4. Dopiero potem analizuj i modyfikuj kod.

Nie twórz aplikacji od nowa, nie mieszaj jej z innymi repozytoriami i nie wymagaj od użytkownika ręcznego kopiowania kodu, jeśli możesz sam wykonać zmianę, test, commit i push.

Po istotnej zmianie workflow lub architektury zaktualizuj START_HERE.md. Po każdej większej łatce zaktualizuj HANDOFF.md.
